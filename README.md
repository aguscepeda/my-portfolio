## Sobre este proyecto

Página web de presentación personal. Reúne mis habilidades técnicas, proyectos académicos, formación, experiencia laboral y datos personales en un solo lugar, pensada para compartir con empleadores.

**Online:** https://aguscepeda.github.io/my-portfolio/

## Características

| Característica | Detalle |
|---|---|
| Fondo animado | Red de nodos en Canvas que cambia de velocidad, dirección y color según el scroll |
| Navegación | Menú fijo que marca la sección activa y barra de progreso de lectura |
| Contenido | Sobre mí, habilidades por área, proyectos, formación, datos personales y contacto |
| Temas | Modo claro y oscuro automático según el dispositivo |
| Responsivo | Se adapta a celular, tablet y escritorio |
| Accesibilidad | Respeta la preferencia de movimiento reducido del sistema |

## Tecnologías

- **HTML5** para la estructura y el contenido.
- **CSS3** con variables, Grid, Flexbox y `color-mix`.
- **JavaScript** puro, sin frameworks ni librerías.
- **Canvas API** para el fondo animado.
- **Google Fonts:** Bricolage Grotesque, IBM Plex Sans y JetBrains Mono.

## Estructura del proyecto

| Archivo | Función |
|---|---|
| `index.html` | Estructura y contenido de la página |
| `css/styles.css` | Estilos, paleta de colores y temas claro y oscuro |
| `js/main.js` | Fondo animado, barra de progreso y menú activo |
| `README.md` | Descripción del proyecto |

## Cómo ejecutarlo en local

No necesita instalación ni dependencias.

1. Cloná el repositorio con `git clone https://github.com/aguscepeda/myportfolio.git`.
2. Entrá a la carpeta `myportfolio`.
3. Abrí el archivo `index.html` en tu navegador.

## Publicación

El sitio se publica con **GitHub Pages** desde la rama `main`, carpeta raíz. Cada `git push` a esa rama actualiza la página en un par de minutos.
